# 과제 요구사항 및 학습 정리

## 필수 요구사항 대응

| 요구사항 | 구현 위치 / 확인 방법 |
| --- | --- |
| Python 3.10 이상, 터미널 CLI | `python -m app` |
| Git 루트 실행·상태·diff 수집 | app/cli.py, app/git_client.py |
| 변경 없음 종료 | API 호출 전에 상태 검사 |
| 환경변수 키, 인증·네트워크 오류 안내 | app/ai_client.py |
| 모델·temperature·토큰 CLI 옵션 | app/cli.py |
| 커밋 제목 생성, 최대 72자 | generate_commit / generate_file_commits |
| PR 제목 최대 80자, 필수 세 섹션과 불릿 | format_pr / pr_template.py |
| 출력 구획 | Commit Message / PR Title / PR Body |
| 안전 모드 | 200줄/20,000자 제한, 파일별 모드 최대 10개 |
| 설치·키 설정·명령·출력·비용 안내 | README.md |
| 원격 자동 반영 제외 | push·PR 등록 모듈 제외, 로컬 커밋은 선택적 `commit --apply` 제공 |

실행 결과는 verification.md에 기록한다. 최종 수정은 아직 로컬 변경이므로
검토·커밋·push 후 제출할 GitHub 브랜치에 반영해야 한다.

## 요청과 응답 흐름

1. `git status`로 변경 여부를 확인하고 `git diff` 및 `git diff --cached`로 입력을 수집한다.
2. 스테이징된 변경이 있으면 우선 사용한다. 새 파일은 스테이징 전에는 diff에 나타나지 않는다.
3. `.env`를 환경변수로 로딩하고 키를 코드에 직접 넣지 않는다.
4. diff의 키를 마스킹하고 선택한 안전 모드의 전송 제한을 적용한다.
5. OpenAI Python SDK가 교육기관의 `/v1/chat/completions`에 인증된 HTTP 요청을 보낸다.
6. 모델·messages·출력 토큰 한도를 전달하고 응답의 텍스트를 추출한다.
7. 길이와 JSON/PR 형식을 검증한 뒤 터미널에 출력한다.
8. 인증 실패·요청 제한·연결 실패·시간 초과 등은 사용자 메시지로 변환한다.

## 파라미터와 품질 제어

- `temperature`: 출력 샘플링의 무작위성을 조절한다. 모델이 지원하는 경우 낮은 값은
  보다 일관된 출력을 유도한다. 모든 모델이 임의의 값을 지원하지 않으므로 기본은 생략한다.
- `max_tokens` CLI 옵션: 요청의 `max_completion_tokens`에 대응한다.
  출력뿐 아니라 추론 토큰도 포함하므로 너무 작으면 응답이 잘릴 수 있다.
- 프롬프트: 한국어·접두사·제목 길이·입력에서 확인되는 내용만 작성하도록 규칙을 둔다.
  PR은 변경 배경, 핵심 변경, 테스트 방법을 분리하고 테스트 통과를 지어내지 않도록 한다.
- 형식 검증: 모델에게 규칙을 요청하는 것만으로는 충분하지 않아 코드가 결과를 검사한다.
  잘못된 JSON이나 누락은 오류로 반환하며 제목 길이는 후처리한다.
- 사람의 검토: diff만으로 작업자의 의도와 실제 테스트 결과를 확정할 수 없다.
  작업자, Why, How to Test 및 체크리스트를 확인한 뒤 적용한다.

## 선택 과제와 증빙 상태

- 템플릿 커스터마이징: 저장소 템플릿 자동 적용을 구현했다.
  컨벤션은 한국어, 커밋 접두사, 제목 길이, 필수 PR 세 섹션 및 미확인 테스트를 체크하지 않는 것이다.
- 실제 이전 미션 저장소에 PR 적용: 로컬 이력에 PR #1 머지는 확인되지만,
  이전 미션 저장소라는 조건과 AI 초안 대비 최종 PR 수정 내역은 확인하지 않았다.
  이미 충족했다고 기재하지 않는다.
- 안전 모드 고도화: 고정 분량 제한과 키 마스킹은 구현했다.
  제한값을 사용자 옵션으로 조정하는 기능은 미구현이다. 필수 기본 안전 모드는 충족한다.

보너스 제출 시 이전 미션 저장소의 PR 링크와 실제 AI 초안/최종 본문을 확보하고,
무엇을 왜 바꿨는지 5~10줄로 기록해야 한다. 실재하지 않는 수정 내역은 만들지 않는다.

## 2026-10-09 변경

사용자 요청으로 로컬 커밋용 `--apply`를 복원했다. 기본 실행은 초안 출력이며,
확인 후 단일/파일별 커밋을 지원한다. 원격 push와 PR 자동 등록은 복원하지 않았다.
